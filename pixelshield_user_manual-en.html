Q1. What is an Invisible Watermark?
Answer:
It's a 'digital stamp' embedded in the photo's pixel data.
PixelShield uses an invisible watermarking algorithm based on image pixel features and digital signal processing technology. It embeds your unique signature into the image data without affecting the normal visual appearance of the photo.
This watermark won't show up in regular image viewing. Users can detect and extract it through the app's 'Verify Invisible Watermark' feature to help verify the source and integrity of the photo.
Q2. What is a SHA-256 file hash?
Answer:
It's the "file hash" of a photo file.
SHA-256 is an internationally standard cryptographic hash algorithm used to generate a unique checksum corresponding to a file's content.
When the content of the same file changes, for example if the image data is modified, the file's hash value will change. So, SHA-256 can be used to verify whether a file remains intact.
It's worth noting that if the image is recompressed, resized, converted to another format, or re-encoded, the file hash may change even if the visual content looks the same.
In file integrity verification scenarios, this hash value can serve as a supplementary verification reference.
Q3. Why can't I see any watermark when looking at photos on my phone gallery or computer?
Answer:
This is exactly the feature of PixelShield's invisible watermark technology.
Traditional visible watermarks can affect the visual quality of images and easily impact user experience. PixelShield embeds watermark information into the image's data features, so regular image viewing tools can't see it directly.
When you need to verify, just import the image into this app's 'Verify Invisible Watermark' page, and it will detect and extract the corresponding watermark information to help confirm the image's source.
Q4. What is Device Binding information?
Answer:
Device Binding information is technical verification information generated locally to support file integrity verification.
PixelShield generates this Device Binding information when you export a Verification Package, using certain system information from the current device and a secure algorithm.
This info doesn't include personal identifiers like phone numbers or names, and it's not uploaded to any server.
The exported Verification Report contains this info, which can help strengthen the integrity verification of the evidence file and make it harder to fake reports across devices.
It''s worth noting that device binding information is just for verification support and doesn't mean tracking the device or the user.
Q5. Where are Verification Records stored? If I delete the original photos from my gallery, will the Verification Record become invalid?
Answer:

1. Data Storage
PixelShield is a fully local, offline tool。
All Verification Records (including signature information, creation time, file hashs, etc.) are stored in the local database on your phone and are not uploaded to any server.
Image processing, metadata handling, and the creation of Verification Records all happen locally on the device.
Additionally, PixelShield can handle metadata like EXIF in images, such as shooting time, device info, GPS location, and other private details, all of which are processed on your device.

2. Impact of Deleting the Original Image
If you delete the original pictures from the album, whether it affects the certificate depends on whether the corresponding Protected Images and Verification Records are still saved on the device.
The Verification information from PixelShield is mainly used to help verify the source and integrity of files.
It's recommended that users properly save the Protected Images and related Verification Reports for future viewing and verification.
Q6. How do I use the 'Export' feature? What should I do with the exported files?
Answer:
For different use cases, PixelShield offers two export methods:

1. Local Backup (Export from Details Page)
On the record details page, click "Export" and the system will generate:
  • [Protected Image File]
  • [Verification Report.txt]
Two separate files will be saved on your phone at: Download/PixelShield_Export
So users can easily view and save them in the file manager.
The Verification Report may include device binding verification information to help enhance file integrity verification.

2. External Rights Protection (Export from Records Page)
On the records list page, select the corresponding record and click 'Export Verification Package.'
The system will automatically generate a .zip Verification Package, which includes:
  • Protected Images;
  • Verification Report.
Then the system will call up the device's sharing feature, and users can send it to a lawyer, content review platform, or other designated recipients as needed.
PixelShield doesn’t offer cloud storage services and has no online upload feature. All image processing and Verification Record generation are performed locally on the user's device.。
